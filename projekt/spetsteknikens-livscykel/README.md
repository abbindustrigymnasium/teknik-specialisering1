# Projekt: Spetsteknikens livscykel

## Syfte

Projektets titel pekar på hur spetsteknik uppstår, sprids och fasas ut. Projektet delas med en annan kurs. I den här kursen hör ämnet ihop med hållbar utveckling inom smarta system. Projektet har ännu ingen fastställd beskrivning.
