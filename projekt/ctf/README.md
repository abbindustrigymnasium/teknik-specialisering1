# Projekt: CTF

## Regeln som gäller alltid

**Du testar bara system som du har uttryckligt tillstånd att testa.** I det här projektet betyder det de miljöer som läraren ger dig eller träningsplattformar vars regler tillåter det. Att försöka ta sig in i andra system kan vara dataintrång och är ett brott, även om du bara vill titta. Läs [kapitel 4](../../kapitel/04-sakerhet-och-ctf.md) innan du börjar.

Hittar du en brist i ett riktigt system ska du inte testa vidare. Berätta för läraren eller för systemets ägare.

## Syfte

Projektets titel pekar på CTF, *Capture the Flag*, en övningsform där säkerhet tränas i lovliga miljöer. Inriktningen i den här boken är försvar, grunder och etik: att förstå hur fel uppstår för att kunna bygga säkrare system. Projektet har ännu ingen fastställd beskrivning.
